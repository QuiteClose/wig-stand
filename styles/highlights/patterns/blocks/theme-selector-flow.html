--- name: Theme Selector Flow source: .theme-selector-flow description: A flat list of all available light and dark colour scheme variants. Rendered server-side from document.style.highlights.available — no runtime config fetch needed. Each pair produces two buttons (light + dark). Selecting any button applies that scheme immediately. config: - property: --space-2xs default: 0.25rem description: Gap between list items and button padding. - property: --space-xs default: 0.5rem description: Horizontal button padding. - property: --radius-s default: 0.25rem description: Corner rounding on option buttons. - property: --size-step--1 default: 0.875rem description: Font size for option labels. notes: | Each button carries a data-set-theme attribute with the exact scheme ID (e.g. highlights-light). On click the scheme is applied to <html data-theme="..."> and persisted to localStorage. Configurable context key:
  • theme-selector-flow.label — accessible list label (default: "Colour schemes")
Dispatches and listens for the highlights:theme custom event so multiple theme controls on the same page stay in sync. In real use, this pattern is typically placed inside a drawer block. ---
