--- name: Theme Toggle source: .theme-toggle description: Light/dark theme toggle for the active highlights pair. Two labelled buttons switch between the pair's light and dark colour schemes. Labels are configurable via context keys with built-in defaults. config: - property: --color-bg-secondary default: transparent description: Background of the active (aria-pressed) button. - property: --stroke default: 1px solid currentColor description: Border on each button. - property: --radius-s default: 0.25rem description: Corner rounding on buttons. notes: | Reads document.style.highlights.available and document.style.highlights.default from the page context to set the data-set-theme attributes. Include in a page layout via <t-include template="highlights:blocks/theme-toggle.html" />. Configurable context keys (all have defaults):
  • theme-toggle.label — label text before the buttons (default: "Theme")
  • theme-toggle.light-label — light button label (default: "Light")
  • theme-toggle.dark-label — dark button label (default: "Dark")
Dispatches and listens for the highlights:theme custom event so multiple theme controls on the same page stay in sync. ---
