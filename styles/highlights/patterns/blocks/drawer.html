--- name: Drawer source: .drawer description: Generic open/close sliding panel. A trigger button toggles the drawer open and closed, changing its label between open and close states. Content slides in via CSS max-height transition. Keyboard-accessible (Escape closes; click-outside closes). config: - property: --stroke default: 1px solid currentColor description: Border on the trigger button and optional panel border. - property: --radius-s default: 0.25rem description: Corner rounding on the trigger button. - property: --transition-movement default: 300ms ease description: Panel slide duration. - property: --space-xs default: 0.5rem description: Trigger button padding. exceptions: - attribute: data-state="open" description: Set on the root element when the drawer is open. CSS uses this to show the panel and swap the trigger labels. notes: | The .drawer__panel content is inlined at the call site — the drawer is a structural primitive. When using in a page template, place inner blocks between the panel's opening and closing tags: 
<div class="drawer">
    <button type="button" class="drawer__trigger" ...>...</button>
    <div class="drawer__panel" id="my-panel">
      <!-- inner content here -->
    </div>
  </div>
Configurable context keys (all have defaults):
  • drawer.id — ID suffix for aria-controls linkage (default: "drawer")
  • drawer.open-label — trigger label when closed (default: "Open")
  • drawer.close-label — trigger label when open (default: "Close")
