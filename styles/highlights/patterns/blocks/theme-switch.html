--- name: Theme Switch source: .theme-switch description: Checkbox slider for toggling between the active highlights pair's light and dark colour schemes. Visually a pill-shaped track with a sliding thumb and ☀/☾ icons. Labels are configurable via context keys. config: - property: --stroke default: 1px solid currentColor description: Border around the switch track. - property: --radius-l default: 2rem description: Full pill rounding of the track. - property: --color-bg-secondary default: transparent description: Track background colour. - property: --transition-movement default: 200ms ease description: Thumb slide duration. notes: | The switch reads data-light-theme and data-dark-theme from the <label> element. These are injected from document.style.highlights.available at render time. Configurable context keys:
  • theme-switch.aria-label — accessible label for the checkbox (default: "Dark mode")
  • theme-switch.icon-light — light-mode icon (default: ☀)
  • theme-switch.icon-dark — dark-mode icon (default: ☾)
Dispatches and listens for the highlights:theme custom event so multiple theme controls on the same page stay in sync. ---
